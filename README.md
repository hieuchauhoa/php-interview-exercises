# PHP/JS Interview Exercises

Tổng hợp các bài test kỹ thuật (job interview tasks): thuật toán và một form liên hệ full-stack.

## Nội dung

- **Câu 1a** — tìm 5 số lớn nhất trong mảng, sắp giảm dần.
- **Câu 1b** (`Cau1_b.html`) — tìm phần tử xuất hiện nhiều nhất trong mảng.
- **Câu 2** (`Cau2/`) — form liên hệ (Họ tên, Email, SĐT, Nội dung) với nút Submit lưu vào database và nút Clear xoá form, backend PHP + MySQL.

## Chạy thử

- Bài thuật toán: mở file tương ứng, chạy bằng ngôn ngữ đã cài đặt (xem `test_work/README.txt`).
- Câu 2: cấu hình kết nối DB trong `Cau2/php/database.php`, host bằng XAMPP/Apache.
